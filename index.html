BeaconGame 信标攻防 Wiki

一局不对称限时攻防：防守方用短暂窗口埋下信标，进攻方随后限时拆除。信标全灭则攻方胜，撑到时间结束则守方胜。这里收录完整的机制设计、技能数值、事件表、配置指令与版本更新日志。

一局怎么打

🛡️放置阶段

守方建设 / 攻方无力

守方睁眼抓紧埋信标；攻方被蒙眼 + 锁在原地，只能转头，物理上无法靠近。约 100 秒。

⚔️进攻阶段

限时拆标 / 事件搅局

攻方解盲、PvP 开启、守方全程发光。约 10 分钟，事件按进度自动触发：空投、增益减益、核打击、移形换影、终局总攻。

运行依赖

硬依赖：领地插件（Dominion 等） 边界、PvP、爆炸、火焰、流体、活塞权限完全由竞技场领地的旗标托管。服务器必须安装领地插件，否则本插件不会加载。详见 竞技场与领地边界.
  • 服务端：Paper（基于 Minecraft Java 版 26.2）
  • 版本：当前发布 BeaconGame-6.5.jar（最新版，见更新日志）
  • 世界：插件自管理三个虚空世界（大厅 / 游戏 / 竞技场），无需自带地形
