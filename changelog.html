信标攻防小游戏历次版本的新增与修复说明。当前最新版为 BeaconGame-6.5。

下载 v6.5 游戏设计文档

6.5　新增「服务器游戏规则」一键设置

  • /bg 菜单新增「服务器游戏规则」项：入口在总控面板「管理」区，点开后列出一批布尔型原版游戏规则（如 doMobSpawning、mobGriefing、keepInventory、doDaylightCycle 等），每项可点击切换开/关。
  • 一键应用到所有世界：界面底部「应用到大厅与竞技场」按钮会把当前配置写入大厅与所有竞技场世界（不影响主世界/下界/末地等其它维度），并提示生效数量。
  • 规则配置存于独立的 plugins/BeaconGame/gamerules.yml（不与 config.yml 混用，避免冲掉中文注释），首次启动自动生成带默认值与注释的文件。
  • 插件启动与执行 /bg reload 时会自动按 gamerules.yml 重新应用到大厅与竞技场世界，保证配置长期生效。

6.4　地图设置新增「进攻方信标指南针」开关

  • 地图设置可开关信标指南针：在 /bg → 地图设置 → 参数区新增一项「进攻方信标指南针」，点击在开启/关闭间切换。开启后，进攻方每局获得一支「信标追踪指南针」，自动指向最近的防守方信标（用于定位并摧毁）；关闭后不再发放，已发放的会被移除。
  • 配置键 attacker-compass（默认 true），保存在 config.yml，与信标个数/时长等并列，对所有地图统一生效。
  • 切换即时生效：开局中打开开关会立刻给在场进攻方补发指南针，关闭则立即收回。

6.3　竞技场全面改名 BeaconGame 1~4 + 旧配置自动迁移

  • 4 张地图统一改名：原来的 default / map2 / map3 / map4 现在叫 BeaconGame 1 / BeaconGame 2 / BeaconGame 3 / BeaconGame 4。竞技场 id、世界名、游戏内显示（大厅 NPC、玩家菜单、排行榜、帮助）全部统一。
  • 旧世界配置自动迁移：插件启动时会把旧 arenas.yml、config.yml（world-settings / lobby-npcs）、displays.yml 里指向旧世界名（如 beacongame_default）的出生点、边界、传送落点、传送 NPC、展示牌等，全部改指到新世界名。无需手动改配置。
  • 旧世界文件夹请手动删除：旧世界（如 beacongame_default、beacongame_2…）不会被自动删，启动后会按新名字新建空虚空世界；请在关服后手动删掉旧的空世界文件夹，避免占空间。
管理员注意
  • 升级后首次启动会自动完成迁移并打印日志；如有异常，插件启动前已对 arenas.yml / config.yml 做了自动备份（最多 5 份），可回滚。
  • 领地仍按 beacongame_<地图名> 命名（如 beacongame_BeaconGame 1），旧 beacongame_default 等领地会成为孤儿，不影响新对局。

6.2　防守方不再被强制选技能 / 默认地图改名

  • 防守方不再被强制选技能：选技能路线界面现在只对进攻方开放。防守方本来就不能使用技能，之前却会在开局被要求选路线，现已修正。
  • 默认对局地图世界改名为「Beacongame 1」：代码默认世界名已从 beacongame_default 改为 Beacongame 1。已在运行的服务器请在 plugins/BeaconGame/arenas.yml 里把 arenas.default.world 改成 Beacongame 1，并关机后把服务器世界文件夹也改名为 Beacongame 1，否则插件会新建一个空世界、原地图消失。

6.1　菜单重设计 / 开局流程修复

  • 玩家菜单：非管理员输入 /bg 直接打开玩家菜单，可一键加入某张地图的等待队列，并提供离开队列、排行榜、帮助、游戏说明、返回大厅等受限操作（不暴露任何管理指令）。
  • 开局改为纯手动：移除了"人数达标自动提示开局"的逻辑；现在只有管理员在菜单点「开始游戏」或执行 /bg start 才会开局。
  • 修复「从菜单设阵营后全员变观战」：原地图设置里有两个开始按钮，其中一个会绕过阵营分配直接空名单开局。现已合并为唯一正确的「开始游戏」按钮（按菜单分配的攻/防阵营组队，未分配者自动均衡补位），并在界面显示当前状态与双方人数。
  • 修复「进入地图提示已在等待队列中」：加入队列前先清除玩家在所有地图队列中的残留记录，可正常切换地图；同时旧的错误开局路径遗留的卡死队列也被一并清除。
  • 管理员菜单更清晰：地图设置界面重新分区（参数 / 出生 / 区域 / 运行），运行区突出「开始游戏」「结束游戏」「阵营分配」，并实时显示对局状态。

6.0　正式上线

这是信标攻防插件对外发布的第一版，玩法与核心功能全部就绪。

怎么玩

  • 在服务器大厅右键传送 NPC，或输入 /bg join 加入队列，等管理员 /bg start 开局。
    • 布置阶段：防守方有时间放置信标、挖地形搭防御；进攻方会被暂时致盲。此阶段不能乱放普通方块，只能放信标。
    • 进攻阶段：PvP 开启，进攻方拿到「信标追踪指南针」去拆信标；拆光全部信标即胜，或防守方守到时间结束即胜。
  • 过程中会按进度触发事件：空投补给、增益/减益、核打击、移形换影、技能强化、终局总攻等。
  • 一局打完，场地和你的背包会自动还原，不用担心东西被改。

你能用的命令

角色命令
玩家/bg join（加入）、/bg leave（退出）、/bg arenas（看场）、/bg top（排行）、/bg settings（设置）、/bg help（帮助）、/bg skill info（技能）、/hub（回大厅）
管理员/bg admin（面板）、/bg start、/bg stop、/bg team、/bg res、/bg region、/bg sign、/bg skill、/bg reload、/bg lobby

技能系统

进攻方可选三条进化路线（突袭 / 干扰 / 辅助），靠本局击杀解锁技能，背包里用「技能核心」右键释放；防守方负责守塔，不装备技能。

战绩与展示

  • 自动记录胜/负、击杀、死亡、破标、场次，可用 /bg top 查看排行。
  • 大厅和游戏里可看到胜场榜、KDR 榜、破标榜和当前对局状态展示牌。

这次版本顺手修好的问题（玩家能感知到的）

  • 清除场地边界后，那片区域不会再被永久锁死、谁都进不去。
  • 管理员改了场地大小后，实际保护范围会立刻按新范围生效。
  • 万一某场没正常套上保护，开局前会重新补好并提醒管理员。
  • 进攻阶段双方 PvP 开关更稳，不会偶尔关不掉或开不出。
小提示
  • 竞技场是虚空地形，落脚和掩体需要自己搭；纯虚空大厅会下坠，记得开飞行或自己铺块地。
  • 本游戏依赖 Dominion 领地插件运行，由服主负责安装与维护。
